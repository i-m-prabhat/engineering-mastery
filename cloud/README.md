# Cloud Computing

**Status: Planned track.**

## Planned sequence

- [ ] Cloud service models and shared responsibility
- [ ] Regions, availability zones, and resilience
- [ ] Compute, storage, networking, and managed databases
- [ ] Identity and access management
- [ ] Deploy a small application to the cloud
- [ ] Infrastructure as code and repeatable environments
- [ ] Monitoring, backups, and reliability
- [ ] Cost estimation, budgets, and cleanup

Cloud lessons should explain provider-specific requirements and identify account setup, expected costs, and resource cleanup before learners begin. Prefer concepts that transfer across providers, and provide local or low-cost alternatives when practical. Use [the lesson template](../docs/LESSON_TEMPLATE.md).
