## How to Use

1. Open the day's README and read the goal and numbered tasks.
2. Add the implementation files listed under What to Add when you start that day.
3. Complete the tasks, then combine them into the requested features.
4. Use Check Your Work to review outputs, boundaries, and failure states.
5. Record your run instructions and tick feature checkboxes only after completing them.

Use Node.js for console work and a browser for DOM, events, storage, and interface projects.
Network exercises need a chosen API or fixture and documented configuration when implemented.
The chat project also needs a local WebSocket server. No dependency installation is needed to read this plan.
