# Security Policy

Engineering Mastery is a learning resource. We appreciate reports that help keep this repository and its examples safe.

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability in a public issue or pull request if doing so could expose people to harm.

Instead, use GitHub's **Report a vulnerability** option on the repository's **Security** tab, if private vulnerability reporting is enabled. If that option is unavailable, contact the repository maintainer privately through the contact method listed on their GitHub profile and include a concise description.

Please include, when possible:

- The affected file, workflow, or example.
- The potential impact and conditions required to reproduce it.
- A minimal proof of concept that does not access other people's data or systems.
- Any suggested mitigation.

Do not include real credentials, access tokens, personal data, or exploit payloads targeting third-party systems in a report.

## Scope and response

Reports concerning this repository's code, documentation, GitHub Actions, or unsafe example behavior are in scope. This project is maintained on a best-effort basis; a response time or security fix timeline is not guaranteed.

Please allow the maintainer reasonable time to investigate and coordinate a fix before making details public.

## Supported versions

Only the latest state of the default branch is actively considered for security fixes. This is a small educational project, not a supported production library.
