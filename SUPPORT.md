# Getting Support

Engineering Mastery is an open learning resource. The easiest way to get help depends on what you need.

## Where to ask

- **Found a mistake or broken example?** [Open an issue](https://github.com/i-m-prabhat/engineering-mastery/issues/new/choose) and include the file path, expected behavior, and actual behavior.
- **Have an idea for a lesson or improvement?** Open a discussion issue using the lesson proposal form and explain the learner outcome you have in mind.
- **Need clarification about contributing?** Read [CONTRIBUTING.md](CONTRIBUTING.md) first, then open an issue if something remains unclear.
- **Think you found a security vulnerability?** Follow [SECURITY.md](SECURITY.md); do not post sensitive details publicly.

## What to include

For reproducible technical problems, please share:

1. The relevant file path or lesson.
2. The command you ran and the expected result.
3. The actual result, including a short error message when applicable.
4. Your Node.js version or operating system if it may affect the issue.

Remove secrets, tokens, personal data, and unrelated logs before posting.

## Expectations

This is a community learning project maintained on a best-effort basis. Help and reviews may take time, and responses are not guaranteed. Please keep questions respectful and focused so other learners can benefit from the answers.
